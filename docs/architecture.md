# Architecture

## Lanes

- **Operations lane (gh-aw):** Request intake from ServiceNow, validation, configuration pull requests.
- **Development lane (Spec Kit):** Triggered when a module is missing; specify → plan → tasks → implement.

Both lanes share the knowledge in this repository (constitution, skills, catalog, policies).

## Open topics

- ServiceNow integration (IntegrationHub → GitHub App → issue; status sync back).
- Cost tracking per request (AI Credits per run linked to the RITM number).
- Distribution of shared knowledge (gh-aw imports, APM, Spec Kit preset).
